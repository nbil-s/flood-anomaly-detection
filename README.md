# Real-Time Flood Anomaly Detection Using IoT Sensors and LSTM Autoencoders

## 1. Project Overview

This project is a prototype flood anomaly detection system that combines Internet of Things (IoT) sensor data with an LSTM Autoencoder to identify unusual environmental patterns that may be associated with flooding.

The system monitors four environmental parameters:

- Water level
- Rainfall
- Temperature
- Humidity

Sensor readings are submitted to a FastAPI backend, where they are validated, processed, and analysed using a trained LSTM Autoencoder. The system uses sequences of 12 sensor readings to identify patterns that differ significantly from learned normal behaviour.

The backend stores sensor readings and anomaly detection results in Firebase Cloud Firestore. A web-based dashboard displays the collected readings, historical trends, and anomaly detection results.

**Project Status:** The software prototype has been implemented and tested using simulated sensor data. Physical IoT hardware integration and real-world flood detection validation remain outstanding.

---

## 2. Project Objectives

The project aims to:

1. Develop an IoT-based environmental monitoring system for collecting relevant sensor readings.
2. Implement an LSTM Autoencoder for detecting unusual patterns in time-series environmental data.
3. Integrate the anomaly detection model with a backend API and cloud database.
4. Develop a dashboard for displaying sensor readings and anomaly detection results.
5. Evaluate the prototype using appropriate testing scenarios and model evaluation metrics.

---

## 3. System Architecture

The system follows this data-processing workflow:

1. Environmental readings are generated by the sensor simulator or collected from an ESP32 when physical hardware is available.
2. Readings are submitted to the FastAPI backend through a REST API.
3. The backend validates incoming readings and stores them in Firebase Cloud Firestore.
4. A buffer collects 12 consecutive readings to form a time-series sequence.
5. The LSTM Autoencoder reconstructs the sequence.
6. Reconstruction error is calculated and compared with the configured anomaly threshold.
7. The detection result is stored and made available to the dashboard.
8. The dashboard displays the latest readings, historical data, and anomaly detection information.

## 6. Requirements

The following software is required:

- Python 3.10 or a compatible version supported by the project's dependencies.
- pip package manager.
- Git.
- A Firebase project with Cloud Firestore configured.
