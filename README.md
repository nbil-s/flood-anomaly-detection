# Real-Time Flood Anomaly Detection Using IoT Sensors and LSTM Autoencoders

## Overview
A prototype flood-monitoring system that combines **IoT sensor data** with an **LSTM Autoencoder** to detect unusual environmental patterns. The project includes a **FastAPI backend** for receiving sensor readings and performing anomaly detection.

> **Note:** The model has only been trained and tested on simulated data. Real-world flood detection performance has not yet been validated.

## Features
- Environmental monitoring (water level, rainfall, temperature, humidity)
- LSTM Autoencoder-based anomaly detection
- FastAPI REST API
- Sequence-based analysis (12 readings)
- Ready for future ESP32 and cloud integration
